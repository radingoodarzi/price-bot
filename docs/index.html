تنظیمات ربات تلگرام: منبع قیمت، ساعت‌ها، طراحی عکس و متن پست.

اتصال به GitHub

توکن فقط داخل همین مرورگر ذخیره می‌شود و به جای دیگری نمی‌رود.
توکن را چطور بسازم؟
  1. GitHub ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token
  2. Repository access: Only select repositories و فقط مخزن همین ربات
  3. Permissions ← Contents: Read and write و Actions: Read and write
  4. Generate، توکن را همین‌جا بچسبان. (جای دیگر نفرست)

وضعیت

بعد از زدن، ربات در ۱ تا ۲ دقیقه عکس را می‌فرستد.

قیمت‌ها (هر ردیف از کجا خوانده شود)

ردیف‌ها و ظاهر عکس ثابت است؛ فقط منبع عدد هر ردیف را تعیین می‌کنی.
TGJU قیمت را به ریال می‌دهد، «تقسیم بر ۱۰» یعنی تومان. برای انس جهانی تقسیم بر ۱.
